# Phase 7 research sources

Reviewed 2026-08-28.

## Audius

- Audius API OpenAPI
  https://api.audius.co/v1

  Current API surface includes users, favorites, user library, playlists, playlist creation/update, track favorites, search and feeds.

- Audius Developer Docs — REST API
  https://docs.audius.co/api/rest-api

- Audius JavaScript SDK
  https://docs.audius.co/sdk/

  The SDK currently advertises search/stream, favorites, reposts, playlist curation and acting on behalf of logged-in Audius users.

- Log In With Audius
  https://docs.audius.co/developers/guides/log-in-with-audius/

  Current guidance documents OAuth 2.0 Authorization Code Flow with PKCE and write/read-only scopes.

## YouTube

- YouTube API Services Developer Policies
  https://developers.google.com/youtube/terms/developer-policies

  Current storage rule reviewed:
  limited Non-Authorized API Data may be stored only as necessary and no longer than 30 calendar days, after which it must be deleted or refreshed.

  Current derived-data rule reviewed:
  API Clients must not use YouTube API Data to create new/derived data or metrics.

- YouTube OAuth for web applications
  https://developers.google.com/youtube/v3/guides/auth/server-side-web-apps
  https://developers.google.com/youtube/v3/guides/auth/client-side-web-apps

  Authorized user actions require OAuth scopes and user consent.

## PWA UX

- MDN PWA best practices
  https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Best_practices

  Recommends app-like UX, deep links, responsive/accessibility support, installability and robust offline behavior.
